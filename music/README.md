# Music

Put royalty-free background tracks here and the agent mixes one under the narration
(quietly, and it ducks under the voice). No files = no music.

Recommended source: **YouTube Studio → Audio library** — filter *Attribution not required*,
genres *Cinematic* or *Ambient*, moods *Dark*, *Dramatic*, *Calm*. Download 10–20 tracks and upload them here
(GitHub: **Add file → Upload files**). mp3, m4a, wav, ogg and flac all work.

Optional: put tracks for one series in a sub-folder named with a word from the series name — the agent prefers them:

```
music/                 general tracks (used for every series)
music/prehistoric/     Prehistoric Giants
music/war/             World War Stories
music/india/           India's Genius
music/myth/            Myth Busters
music/dig/             Dig Discoveries
music/timeline/        Timeline Twists
```

Turn music off with the repository variable `MUSIC` = `off`.
